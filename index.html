Main Platform

RabbitRobot Platform: a self-built real AMR system

Role: individual builder / system integrator · Robotics, ROS 2, Nav2, SLAM, Web tools

RabbitRobot is my long-term robot platform. It is not a static demo page: it records how a real AMR is assembled, wired, mapped, controlled, visualized, and used as a testbed for VLN-style navigation tasks.

  • Built the physical robot stack from chassis, motor drive, sensors, wiring, and field tests.
  • Connected ROS 2 / Nav2 / SLAM / Web visualization into a repeatable robot experiment workflow.
  • Uses real robot evidence to support future VLN waypoint execution and failure recovery research.

Research Line

VLN / VLR on real AMR: from language goals to recoverable navigation

Direction: Vision-Language Navigation · semantic goals, map grounding, waypoint execution

My VLN work is organized around a practical question: when a robot receives a natural-language goal, how can the system ground it, execute it, notice deviation, and recover on a physical platform?

  • Uses AMR2 as the execution layer for language-conditioned waypoint and route experiments.
  • Focuses on deviation detection, semantic subgoals, real robot status, and rosbag-based analysis.
  • Keeps classical Nav2 baselines visible, so learned policies can be compared against stable robot behavior.

AMR System

AMR2 Coverage and Safety System

System: hub-wheel AMR · map-aware coverage · Web 3D console · safety chain

AMR2 turns a hand-built chassis into a system that can map, localize, preview routes, and validate coverage paths before real execution. It is the engineering layer that makes robot experiments inspectable.

  • Integrates MID360, Fast-LIO, ICP alignment, Nav2 MPPI, DS20270C CAN drive, speed smoothing, and collision monitoring.
  • Transforms map-aware coverage planning into visual Web tooling with footprint and path checks.
  • Emphasizes testability: dry-run, RViz, Web preview, and real robot field evidence all point to the same system.

Mapping Chain

D435 / Unitree L1 / RTAB-Map multi-sensor mapping

System: RGB-D, LiDAR, IMU, RTAB-Map, FAST-LIO2 · 2025.9

This line builds maps and sensor data for AMR navigation. It combines RGB-D camera, Unitree L1 LiDAR, external MPU6050 IMU, ROS 2 launch files, RViz, and RTAB-Map / FAST-LIO2 experiments.

  • Compensates for D435 without internal IMU by adding Jetson + MPU6050 ROS 2 integration.
  • Documents driver setup, point cloud visualization, launch files, TF, synchronization, and mapping workflow.
  • Provides map production capability for navigation, coverage planning, and future VLN experiments.
