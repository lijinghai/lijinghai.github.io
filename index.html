研究方向

长程视觉语言导航 研究历史语义地图能否帮助发现偏航，如何用空间一致性区分任务进展与误匹配，并选出值得回访的恢复锚点。

真实移动机器人系统 将底盘通信、传感器时间戳、TF 与导航接口放到同一条可检查的链路中，以实机反馈定位问题，积累可复现的失败案例。

建图与执行验证 关注地图几何、跨视角物体关联与位姿不确定性；分别检查感知输入、计划路径和实际轨迹，再判断恢复是否有效。

工具链： ROS 2, Nav2, SLAM, LiDAR, RGB-D, VLM / VLA, Web tools.

研究概况
  • 方向长程 VLN、历史语义地图与偏航恢复
  • 进度已有回放与感知检查；可靠地图和自主恢复仍待验证
  • 工程自建 AMR / 机械臂、传感器、ROS 2 / Nav2 / Web
