项目

以自建 AMR 与调试工具为工程基础，延伸到现有模型部署、操作硬件联调和数据采集。以下记录个人工作与验证范围。

R1 Pro · 轮式双臂 VLN 实验平台

我将上游 MiniCPM-RobotTrack 迁移到轮式双臂平台的本体 GPU，在独立环境中检查实采图像回放、历史窗口与会话重置，并梳理差速底盘接口。当前验证的是保存图像的本体推理，尚未接入实时传感器与运动闭环。

ROS 2 · RGB-D · 2WDMiniCPM-RobotTrack
查看 R1 Pro VLN 详情 ↗
技术细节

部署与回放：核对 179 个源码及模型文件的 SHA-256；将 32 帧实采头部相机图像保存后，在本体 RTX 4090 Laptop GPU 上回放。34 次检查覆盖轨迹输出、31 帧历史窗口与两次会话重置，并非导航成功次数。

验证边界：八点预测轨迹仅写入文件，推理测试未创建 ROS 运动发布器。相机到机身 TF、控制权归属、深度距离约束与失效停车仍需联调；平台移动与姿态视频不代表模型自主导航。

DAS Ego × UMI · 具身操作采集链

我完成 DAS Ego 与 UMI 的佩戴、配对和双手桌面操作记录，正在整理第一视角观察与末端动作片段。视觉、姿态、夹持与接触事件的时间对齐仍在推进；现有实操素材尚不等于经过质量验证的训练数据集。

技术细节

设备背景：六路 RGB、约 270° 水平视野、六轴 IMU 与 MCAP 格式来自产品资料；这些规格说明采集入口，不代表已完成的同步或数据质量评测。

整理工作：核对视觉、姿态与双手动作时间戳，组织可复盘片段。动作切片、接触标注、VLA 示教数据与策略评估仍需进一步建立和验证。

Go2X × MiniCPM-RobotTrack

我为上游 MiniCPM-RobotTrack 适配 Go2X 的 RGB-D 与里程计输入，分开处理彩色图像和测距深度，并检查跨机传输、时间戳及数据新鲜度。已有短时 Shadow（仅推理、不下发运动控制）记录；相机外参、深度保护与真机闭环仍待验证。

RGB-D · Odom · ROS 2Shadow · 不下发运动控制
查看完整工程记录 ↗
技术细节

输入适配：rclpy 中继与 rosbridge 传输 RGB-D / Odom，YAML 明确机器人接口。RGB 使用压缩与图像缩放；深度解析 compressedDepth、保留 16UC1 并以最近邻缩放，避免插值改变测距值。

限定测试：18 秒 Shadow 样本完成 140 次推理，未记录模型或传感器故障。31 帧上下文与八点轨迹来自上游模型；该样本不证明长期连接可靠性，控制桥保持锁定，视频不作为模型自主行走证据。

RabbitRobot Platform

AMR2 是我的主要工程实验平台：从机械、电控、线束和传感器安装，接到底盘 CAN、ROS 2 与导航接口。我对齐 CAD / 显示模型、TF 和规划轮廓，适配覆盖路径与 Nav2。已有真车转向记录及指令链路空跑检查，完整自主任务尚待现场验收。

研究方向

长程视觉语言导航 研究历史观测进入可信记忆的条件，结合指令、历史与空间转移检查偏航，并考察恢复参考状态的选择依据。

真实移动机器人系统 从底盘通信、传感器时间戳和 TF 到导航接口，逐层核对输入、坐标与状态反馈，用日志和现场记录定位问题。

建图与实验验证 关注地图几何、跨视角物体关联与位姿不确定性，将感知记录、规划输出和实际执行分开核验，为后续恢复实验建立依据。

工具链： ROS 2, Nav2, SLAM, LiDAR, RGB-D, VLM / VLA, Web tools.

研究概况
  • 方向长程 VLN、可信历史与恢复参考状态
  • 进度受控回放、真机感知与地图输入检查
  • 工程AMR 搭建、机械臂联调与 ROS 2 / Nav2 / Web 工具
