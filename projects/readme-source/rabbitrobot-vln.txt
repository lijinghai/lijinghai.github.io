# RabbitRobot 2025 Project Archive

**时间**：2025.12

**定位**：真实 AMR 系统图文档案与 VLN 正在推进的研究线

## 项目说明

RabbitRobot 2025 阶段重点整理真实 AMR 原型、SLAM / Nav2、多传感器建图、Web 控制台、覆盖路径规划和清扫/服务机器人原型。这个页面用于展示已经搭起来、拍得到、能复盘的机器人系统基础，而不是把 VLN 提前写成已经完成的成果。

## 为什么这样写

RabbitRobot 不是单一小车 demo，而是一条围绕真实机器人系统逐步展开的研发链路。2025 阶段最重要的价值，是把“能动的底盘、能看的地图、能跑的导航、能调试的 Web 控制台、能复盘的图文资料”放到同一个项目里，形成继续推进 VLN / VLR 的基础。

## VLN / VLR 正在推进

VLN / VLR 的重点不是“调用一个模型让它说路线”，而是让语言目标能被真实机器人系统检验。2025 阶段先把底盘、地图、Nav2、Web 控制台和覆盖路径跑通；现在正在把语言指令、视觉观测、地图 grounding、waypoint 策略和失败恢复接进去，才能判断模型到底有没有让机器人更会执行任务。

当前推进路线：

1. 固定 AMR2 / Nav2 baseline，记录成功率、路径长度、卡停和避障情况。
2. 整理“去门口”“绕开杂物到桌边”“覆盖这片区域”等可复现实验指令。
3. 把语言目标对齐到地图区域、视觉观测、局部目标点和机器人当前状态。
4. 让 waypoint 继续走 Nav2、速度平滑、避障和底盘安全链，而不是绕开工程系统。
5. 重点记录走偏、误判目标、绕行失败和恢复成功案例，形成可比较指标。
