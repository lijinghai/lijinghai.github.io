What Is Done

2025 阶段先沉淀的能力

  • 搭出 RabbitRobot AMR 原型，把底盘、电机、传感器、供电和 ROS 2 运行环境串起来。
  • 用 D435、Unitree L1、MPU6050、RTAB-Map / FAST-LIO2 等链路积累多传感器建图经验。
  • 把 Nav2 单点导航、地图可视化、机器人状态和 Web 控制台做成可以展示和复盘的入口。
  • 围绕清扫/覆盖场景做地图约束下的覆盖路径规划，为 AMR 区域作业准备算法基础。

Next Plan

VLN 为什么是下一步计划

VLN / VLR 不是 2025 阶段已经完成的结果，而是建立在 AMR、地图、导航、安全链和数据记录之上的下一层能力。先让机器人稳定知道“自己在哪、地图是什么、目标点怎么跑、失败如何记录”，再让语言任务进入系统，才有真实可评估的意义。

1. AMR Baseline

先跑稳 SLAM、定位、Nav2、速度链和基本避障，形成可复现的导航 baseline。

2. Data Record

记录地图、视觉帧、轨迹、目标点、失败片段和 rosbag，让实验可以回放。

3. Language Goal

把“去桌边”“绕过障碍到门口”等指令转成可落地的语义目标和中间 waypoint。

4. Visual Grounding

把视觉观测、地图区域和机器人位姿对齐，判断目标是否可见、可达、需要绕行。

5. Recovery Check

重点评估走偏、目标误判、绕行失败和恢复策略，让 VLN 有真实指标。

项目说明

RabbitRobot 2025 阶段重点整理真实 AMR 原型、SLAM / Nav2、多传感器建图、Web 控制台和覆盖路径规划。这个页面用于图文展示已经搭起来的机器人系统基础，而不是宣称 VLN 已经完成或已进入当前主线。

关键记录

  • AMR 原型、传感器接入、导航界面和项目架构图构成了 2025 阶段的公开证据。
  • 多传感器建图和 Web 控制台让后续实验可以被看见、被调试、被复盘。
  • 覆盖路径和清扫场景为移动机器人区域作业准备了可继续扩展的算法接口。

与 VLN 的关系

VLN / VLR 是下一步计划：等 AMR baseline、地图、导航安全链和数据记录稳定后，再把语言目标、视觉 grounding、waypoint 策略和失败恢复评估接入真实机器人。
