Rabbit-RobotNav: History-Aware Error Diagnosis
and Recovery Anchors for Vision-Language Navigation

MASTER'S THESIS PROJECT · WORK IN PROGRESS

Jinghai Li

Long-horizon ground-robot navigation research · 2026

▤  Thesis ◉  Experiments ◈  Code

Abstract

Errors in long-horizon vision-language navigation can accumulate beyond a single observation. Rabbit-RobotNav studies whether trusted semantic-spatial history can support label-free deviation diagnosis and selection of a reliable recovery anchor. It compares the current observation and post-action state with instruction progress, historical states, and spatial transitions. The present evidence supports controlled-case diagnosis and static RGB-D projection checks; it does not establish improved navigation success or autonomous closed-loop recovery.

Contributions

  1. Trusted historical memory. Keep raw observations separate from reliability-gated semantic-spatial states.
  2. Multi-source consistency diagnosis. Check instruction progress, historical evidence, and state transitions without reading evaluation labels.
  3. Recovery-anchor selection. Locate the error boundary and retrieve the last reliable state with supporting evidence; execution remains future work.

Method Overview

The central question is not only where the robot is now, but whether its current state agrees with where the instruction and trusted history say it should be.

The proposed stack draws on MiniCPM-RobotTrack for vision-language grounding and SpaAct for dynamic spatial relations. Trusted history and consistency checks support deviation diagnosis and anchor selection; SimpleNav/ROS 2 recovery execution is not yet validated.
