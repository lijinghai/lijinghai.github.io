Rabbit-RobotNav: History-Aware Error Diagnosis
and Recovery Anchors for Vision-Language Navigation

MASTER'S THESIS PROJECT · WORK IN PROGRESS

Long-horizon ground-robot navigation research · 2026

Thesis Experiments Code

Abstract

Errors in long-horizon vision-language navigation can accumulate beyond a single observation. Rabbit-RobotNav investigates whether semantic-spatial history can support label-free deviation diagnosis and recovery-anchor selection. The proposed framework compares observations with instruction progress, historical states, and spatial transitions. Controlled MP3D cases and static RGB-D checks offer preliminary evidence; a moving-robot trial exposed an object-identity failure. Reliability gating, navigation gain, and autonomous recovery remain unverified.

Research Directions

  1. History with an evidence gate. Separate raw observations from semantic-spatial states; the reliability gate still needs validation.
  2. Multi-source diagnosis. Test instruction, history, and transition consistency without reading evaluation labels.
  3. Recovery-anchor candidates. Retrieve a supported earlier state after detecting deviation; robot execution remains future work.

Method Overview

The central question is not only where the robot is now, but whether its current state agrees with where the instruction and trusted history say it should be.

The proposed stack draws on MiniCPM-RobotTrack for vision-language grounding and SpaAct for dynamic spatial relations. Current implementation checks require stronger evidence-sufficiency and history-writing gates; SimpleNav/ROS 2 recovery execution has not been validated.

Real-Robot Setup

The WheelTec Astra passed the static projection check, but manual movement split one user-confirmed chair into two object IDs. The image pair shows the target before and after movement; the selected-depth trace is a clue, not proof of the split's cause.

Latest gate · 2 Oct 2026. A historical static run lost its target at step 68, but its saved screenshot stops at step 50. A new stationary attempt stopped after two frames (1.10 s) at the unchanged 0.50 s continuity gate—not at TARGET_LOST.
