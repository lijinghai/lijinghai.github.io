RabbitRobot_ROS2_Web

AMR Web 控制台

ROS2 Web 控制台把地图可视化、图层开关、导航控制、任务管理、状态监控和日志入口搬进浏览器，减少机器人调试对 RViz 单机环境的依赖。

Time · 2026.07 Source · ROS2 Web console Context · Robot Web Tools

What It Does

项目做的是什么

  • React/TypeScript 前端，通过 WebSocket/rosbridge 接入 ROS/ROS2 数据。
  • 支持地图、激光、点云、路径、机器人模型等图层化可视化。
  • 面向真车调试，把单点/多点导航、重定位、手动控制和系统状态放到统一界面。

Implementation Notes

控制台能力拆解

为什么要做 Web 控制台

传统机器人调试往往分散在 RViz、终端、参数文件和日志窗口里。这个控制台把高频操作收拢到浏览器：看地图、发目标点、检查机器人状态、切换图层、观察路径和回看异常，尽量减少“一个任务开一堆窗口”的调试成本。

关键能力

  • 地图与图层：栅格地图、路径、机器人模型、激光/点云等信息按图层管理，便于定位问题来源。
  • 导航与重定位：支持 Web 端目标点设置、单点导航、路径结果观察和初始位姿设置。
  • 真车状态：把 AMR2 的位置、速度、连接状态和操作反馈集中展示，服务现场调试。
  • ROS/ROS2 接入：通过 WebSocket / rosbridge 连接机器人系统，为后续覆盖地图和 VLN 任务入口留出接口。
