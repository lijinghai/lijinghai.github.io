# RabbitRobot_Sweeper V2.0

**时间：** 2026.11
**定位：** 固定地图下的实车覆盖清扫平台。

## 项目说明

从 V1.0 硬件原型继续迭代，完成电路改造、独立布线、底盘驱动、清扫机构和传感器集成；基于 ROS 2 / Nav2 实现定位、覆盖规划、任务执行与 Web 操作流程。V2.0 是展示版本名称，代码继续使用已有实车基线分支。

## 已有功能

- LTME-02A 二维雷达、轮速与 IMU 运动估计、AMCL 固定地图定位和 TF 坐标变换。
- 网页查看地图、激光预览和位姿，设置实际初始位置与朝向。
- 绘制清扫区域，编辑地图与台阶禁行区，生成覆盖作业段和转场路径。
- 通过 Nav2 执行任务，保留速度平滑、碰撞监测、底盘就绪检查和停止链路。
- 任务启动、取消、停止、重新定位及日志导出。

## 代码入口

- ROS 工程：`ljh_amr2_hubwheel_drive`，分支 `baseline/sweeper-real-v1-ros`。
- Web 工程：`ljh_amr2_hubwheel_drive_web`，分支 `baseline/sweeper-real-v1-web`。
- `ljh_robot_coverage` 负责覆盖区域、路径和执行相关接口。
- `start_clean_console.sh` 是车端统一控制台启动入口，默认驻车、不启动清扫刷。进入页面与生成路径本身不下发运动任务。

## 近期排查

转弯激光错位需要核对扫描时间、旋转补偿方向、角速度与对应位姿。重定位需要检查实际位姿、AMCL、动态 TF 与地图身份。任务停滞则继续检查 Costmap 扫描供给、DDS 回调、节点状态、底盘允许状态及任务绑定。网页显示过滤不能替代物理定位精度验证。

## 真实验证与边界

2026-11-05 的 R101–R146 共 46 次实车尝试，39 次完成、7 次失败，最长连续完成 22 次。完成轮次行驶距离约 3.35–5.01 米。6 次失败涉及路径无进展或扫描供给异常，另有 1 次底盘就绪检查失败。

统计对应当时地图、路线与配置；不代表所有场地和路径的保证。显示链路过滤不可信激光点，越界点为零不等于真实定位误差为零。本次展示网站更新没有新增实车测试。

整车照片、电气照片、真实 Web 截图、两段现场视频及逐轮 CSV 均可在 V2.0 详情页查看。

## 后续方向

在稳定的地图与执行链路上继续积累不同路线的完成与失败记录，并为未来语言任务到清扫区域的转换准备接口。当前展示的是人工框选区域后的覆盖流程。
